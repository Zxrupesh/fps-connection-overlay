# FPS & Connection Overlay - Chrome Extension

This Chrome extension displays an overlay on any webpage showing:
- **Frames Per Second (FPS)**
- **Internet connection info** (like downlink, effective type, and latency)

You can toggle the overlay visibility from the extension popup and drag it anywhere on the screen. The position is remembered across sessions, and it auto-hides when inactive for 30 seconds.

---

## 📦 Features

- 🖥 Real-time FPS counter
- 🌐 Connection status monitor
- 📌 Draggable overlay with position saving
- 💤 Auto-hide after inactivity (30 seconds)
- 🔘 Toggle via popup menu
